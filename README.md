# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**. This was one of my first web development projects and helped me understand the fundamentals of JavaScript and DOM manipulation.

## 🚀 Live Demo

**[Play Tic-Tac-Toe](https://github.com/U93412K/TIC-TAC-Game/tree/main)**

## 🛠️ Technologies Used

* **HTML5** — Structure of the game
* **CSS** — Styling and layout
* **JavaScript** — Game logic and user interactions

## ✨ Features

* Two-player Tic-Tac-Toe gameplay
* Interactive game board
* Automatic winner detection
* Draw detection
* Game reset functionality
* Simple and responsive interface

## 📚 What I Learned

This project helped me learn and practice:

* DOM manipulation
* JavaScript event handling
* Functions and conditional logic
* Working with arrays
* Handling user interactions
* Implementing game logic
* Connecting JavaScript with HTML and CSS

1. Clone the repository:

```bash
git clone https://github.com/u93412k/TIC-TAC-Game.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
